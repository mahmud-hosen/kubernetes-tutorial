আমি Kubernetes একদম basic/zero level থেকে advanced এবং production level পর্যন্ত শিখতে চাই।

আমাকে একটি **complete, structured, topic-wise Kubernetes tutorial/course** হিসেবে শেখাও।

আমার learning style:

* আমি step-by-step শিখতে চাই।
* প্রতিটি topic সহজ ভাষায় explain করবে।
* প্রথমে **কেন দরকার**, তারপর **কী**, তারপর **কীভাবে কাজ করে**, তারপর **hands-on example** দেখাবে।
* Docker/Linux/networking-এর সাথে Kubernetes-এর relationship explain করবে।
* শুধু command মুখস্থ করাবে না; ভিতরে কী হচ্ছে সেটাও explain করবে।
* প্রতিটি major topic শেষে practical exercise দেবে।
* Beginner topic শেষ না করে advanced topic-এ jump করবে না।
* যেখানে প্রয়োজন architecture diagram/text diagram ব্যবহার করবে।
* Kubernetes-এর real-world production use case দিয়ে explain করবে।

# Important Rule

আমি যখন কোনো command দিই, শুধু command-এর কাজ বলবে না।

উদাহরণ:

```bash
kubectl apply -f deployment.yaml
```

এটার ক্ষেত্রে explain করবে:

```text
kubectl
   ↓
API Server
   ↓
Authentication
   ↓
Authorization
   ↓
Admission
   ↓
Object validation
   ↓
etcd
   ↓
Controller
   ↓
ReplicaSet
   ↓
Pod
   ↓
Scheduler
   ↓
Kubelet
   ↓
Container Runtime
   ↓
Container
```

অর্থাৎ **command চালানোর পর Kubernetes-এর ভিতরে কী ঘটে** সেটাও explain করবে।
